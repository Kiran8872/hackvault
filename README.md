# HackVault — Collaborative Idea Platform

Welcome to the HackVault repository. This project consists of a high-performance Spring Boot backend and a premium React + Vite frontend.

## 📁 Project Structure

```text
/
├── backend/          # Spring Boot application (Java 21)
├── frontend/         # React + TypeScript SPA (Vite)
├── Dockerfile        # Production build configuration
├── .gitignore        # Comprehensive workspace ignore rules
└── README.md         # You are here
```

## 🚀 Getting Started

### Backend
1. Ensure Java 21 is installed.
2. Navigate to `/backend`.
3. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```

### Frontend
1. Ensure Node.js (v18+) is installed.
2. Navigate to `/frontend`.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run in development mode:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Vite, Glassmorphism CSS.
- **Backend**: Java 21, Spring Boot, Spring Data JPA.
- **Tools**: Maven, NPM.
